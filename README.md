# Suba Tours Pondicherry 🌴🚗

A luxury dark forest green travel, tour package, and car rental web application for **Suba Tours & Travels**, Pondicherry / Puducherry.

## 🌟 Highlights & Features
- **Commercial Fleet & Rentals**: Dedicated showcase for Tempo Traveller (12-20 seater), Toyota Innova Crysta, Toyota Etios, and Maruti Swift Dzire.
- **Self-Drive Rental**: Dedicated self-drive page with flexible booking options, transparent terms, and direct WhatsApp booking.
- **Pondicherry Tourist Circuit**: Curated sightseeing spots including Promenade Beach, White Town / French Quarter, Auroville Matrimandir, Paradise Beach, and Rock Beach Pier.
- **18+ Years of Travel Mastery**: Led by proprietor **S. Thinagaran**.
- **Instant WhatsApp Booking**: Pre-populated dynamic booking quotations sent directly to WhatsApp.
- **Responsive & Modern UI**: Built with React, Tailwind CSS, Lucide Icons, and smooth micro-interactions.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production
```bash
npm run build
```
The production bundle will be generated in the `dist/` directory.
